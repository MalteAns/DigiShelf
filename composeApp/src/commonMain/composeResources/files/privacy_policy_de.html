2 Art und Umfang der Datenverarbeitung

2.1 Google Books API

2.1.1 Welche Ihrer Daten verarbeitet werden

Die folgenden Daten werden bei Bedarf an die API gesendet:

  • Eingegeben oder eingescannte ISBN
  • Eingegebener Titel
  • Eingegebener Autor

2.1.2 Beschreibung und Zweck der Datenverarbeitung

Um anhand der ISBN, des Titels und des Autors Buchinformationen abzurufen, werden die eingegebenen Daten an die Google Books API gesendet.

2.1.3 Rechtsgrundlage für die Datenverarbeitung

Die Verarbeitung Ihrer Daten erfolgt auf Grundlage von Art. 6 Abs. 1 lit. b DSGVO zur Erfüllung des Nutzungsvertrags, um Ihnen die gewünschten Buchinformationen bereitzustellen.

2.1.4 Wie lange Ihre Daten gespeichert werden

Siehe https://books.google.com/googlebooks/privacy.html

2.1.5 Wer Ihre Daten erhält

Die Daten werden an die Google Books API gesendet. Siehe auch https://books.google.com/googlebooks/privacy.html
